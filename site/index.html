Features

Everything runs locally. Everything is routable.

Dual MCP client / server

Frozen Fish speaks MCP both ways — it hosts 12 built-in servers for your agents and attaches to external stdio MCP servers from your config, all behind one sandboxed registry.

GPU-aware router

Live scoring: 0.5·(1−util) + 0.3·warm + 0.2·(1−queue/64). Sticky sessions get a +0.25 bonus. Switch policies at runtime: gpu_aware, round_robin, least_queue.

Three-layer context

CAG (precomputed KV ≤ 32 768 tok) → CAR (vectors partitioned by MCP tool boundary) → RAG (top-k 5, λ=0.7 MMR, HyDE). Hybrid resolution with per-layer confidence.

Workflow engine

YAML pipelines with cron / interval / event triggers, per-step retry (3 attempts, 2s exponential backoff), SQLite state, and a dead-letter queue.

Security by default

RBAC roles (admin / operator / viewer), PII-redacted SQLite audit log, egress allowlist for every outbound HTTP call, path-denied sandbox for tools.

Zero hard dependencies

Pure standard library at runtime. PyYAML is optional — a built-in mini-YAML parser covers the config surface. Python ≥ 3.10, one pip install away.

MCP registry

12 servers. One sandbox.

Every tool call — built-in or external stdio — lands in the same registry, with the same sandbox: .ff/sandbox workdir, denied paths (/etc, /usr, /boot, /var), 1 MiB output cap, 30 s timeout.

Context engine

CAG → CAR → RAG. One resolve() call.

Each query walks the layers in order. The first layer that answers with confidence ≥ 0.35 wins. Confidence falls through; counts are observable per layer.

CAG
Cache-Aware Generation

Prefaces with stable fingerprints are precomputed into KV entries (≤ 32 768 tokens). Warm hits reply in ~85 ms TTFT. ff context cag build|invalidate.

CAR
Context-Aware Routing

The vector index is partitioned by MCP tool boundary. A query that names git only scans the git partition — cheaper, no cross-tool bleed.

RAG
Retrieval fallback

Top-k 5, similarity threshold 0.35, MMR (λ=0.7) for diversity, HyDE-style query expansion, RRF merge for multi-source. ff rag reindex.

GPU router

Score every backend, every request.

Scoring
score = 0.5·(1 − utilization)
      + 0.3·warm(model)
      + 0.2·(1 − queue / 64)
      + 0.25·sticky(session)

Weights are config-tunable and must sum to 1.0. Unhealthy backends score −1 and are skipped. Sticky sessions pin to their last backend while it stays healthy.

Discovery

Frozen Fish never launches anything — it discovers:

  • OLLAMA_HOST → Ollama backend (CPU/Metal/CUDA)
  • VLLM_HOST → vLLM server (CUDA/ROCm)
  • LMSTUDIO_PORT → LM Studio (Metal/CUDA)

Plus llama.cpp, Transformers, and any OpenAI-compatible endpoint from config. CUDA utilization is probed via nvidia-smi --query-gpu=utilization.gpu; other accelerators report 0 until a probe lands.

Config

One YAML, versioned.

Schema version: "0.9". Defaults ship in-package; $FF_CONFIG or --config override. PyYAML optional — built-in parser handles the schema.

version: "0.9"
orchestrator:
  mcp:
    servers: []              # external stdio MCP servers
    sandbox:
      enabled: true
      workdir: ".ff/sandbox"
      deny_paths: ["/etc", "/usr", "/boot", "/var"]
      max_output_bytes: 1048576
    timeout_ms: 30000
  routing:
    strategy: backends       # gpu_aware | round_robin | least_queue
    fallback: local
    weights: {util: 0.5, warm: 0.3, queue: 0.2}
    sticky: true
  context:
    cag: {enabled: true, max_tokens: 32768, warm_on_boot: true}
    car: {enabled: true, partition_by: tool}
    rag: {enabled: true, top_k: 5, similarity_threshold: 0.35}
    mmr: {enabled: true, lambda: 0.7}
  security:
    rbac:
      roles:
        admin: ["*"]
        operator: ["workflow:*", "gpu:*", "mcp:call"]
        viewer: ["*:read"]
      users: {me: admin}
    audit: {enabled: true, path: ".ff/audit.db"}
    egress_allowlist: []     # empty = deny all egress
  web: {host: 127.0.0.1, port: 8321, auth_token: null}
  workflows:
    dir: "workflows"
    state_db: ".ff/workflows.db"
    retry: {max_attempts: 3, backoff_seconds: 2.0}
Security

Local means controlled.

RBAC

Roles with per-segment wildcards. admin gets *; operators get workflow + gpu + mcp:call; viewers get read. ff user add alice --role operator.

Audit

Every action lands in SQLite with PII redaction (emails, CN/US phones, SSN, API keys → [REDACTED]). ff audit tail --since 1h, ff audit export --format json.

Egress

Hostname, *.wildcard, and CIDR allowlists guard every outbound HTTP call. Empty allowlist = no egress. The sandbox denies /etc, /usr, /boot, /var.

FAQ

Questions.

Do my prompts leave my machine?
No. Inference goes only to backends you run locally (Ollama, vLLM, LM Studio, llama.cpp). Egress is allowlisted and empty by default, so even tool calls can't phone home.
Can I use a hosted OpenAI-compatible API?
Yes — add any OpenAI-compatible endpoint to orchestrator.backends in your config. It participates in the same scoring router as local backends.
What's the difference between CAG, CAR and RAG?
CAG = precomputed KV cache for stable prefices (~85 ms TTFT). CAR = vector index partitioned by MCP tool boundary (cheap, no cross-tool bleed). RAG = generic top-k retrieval with MMR + HyDE, the fallback layer. One query walks CAG → CAR → RAG and takes the first confident answer.
Does Frozen Fish launch my GPU servers?
No. It discovers (env vars + config) and probes. You own the lifecycle of Ollama/vLLM/LM Studio; Frozen Fish routes around what's healthy.
Why zero hard dependencies?
So pip install frozen-fish works everywhere Python ≥ 3.10 does, on the flakiest network. PyYAML is optional; a built-in parser covers the config schema.
Is there a web UI?
Yes — ff orchestrator start serves a dashboard at http://127.0.0.1:8321 with live backend, context, and workflow panels. Bearer-token auth is optional in config.
